# 第三阶段｜接口与系统设计：食堂点餐订单

本阶段在第二阶段的食堂点餐项目上继续，围绕“下单”依次完成接口设计、数据设计和系统设计。学生先写设计文档，再让 Coding Agent 评审或实现，最后亲自运行、对照设计验收，并说明自己的取舍。

| 任务 | 学习重点 | 本任务完成时能看到什么 |
|---|---|---|
| 3.1 接口设计 | 资源与路径、状态码、接口文档、对照验收 | 提交订单与查询订单接口，以及接口文档 |
| 3.2 数据设计 | 拆表、主键与外键、价格快照、事务 | 订单拆成订单表和订单明细表，接口行为不变 |
| 3.3 系统设计 | 模块职责、订单状态、顺序图、异常处理 | 带模拟支付的完整下单流程 |

## 学生完成方式

每项任务保留“独立设计 → Agent 评审或复述 → 运行证据 → 对照设计的判断与修订”。不要求背诵规范，但要能说明自己为什么这样设计、交给 Agent 的要求是什么、运行结果与设计是否一致，以及不一致时如何判断。

三个任务在同一个代码项目上依次完成：任务 3.2 要用任务 3.1 的验收项做回归验收，任务 3.3 在任务 3.2 的数据结构上增加支付和异常处理。每项任务的填写模板可作为该任务的学习记录；代码、设计文档、截图和测试证据按任务 README 中的清单一同提交。

## 范围说明

阶段三只围绕下单展开：提交订单、查询订单、订单明细、订单状态和模拟支付。不做登录、真实支付、自动对账、消息队列、ORM 和数据迁移。分层与架构风格留到第六阶段。
