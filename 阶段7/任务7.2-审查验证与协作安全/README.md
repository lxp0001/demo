# 任务 7.2｜审查、验证与协作安全

## 任务目标

审查老师提供的、由 Agent 生成的改动，找出问题并证明；建立验证闭环；设置使用 Agent 的权限边界；写使用复盘。

## 技术与范围

- 被审查对象：老师提供的“订单取消与退款状态”功能的 Agent 改动（一个分支或补丁），看起来都能运行，其中包含若干问题，不提示数量和位置。
- Agent 工具：自选，可以用来辅助审查，但要先自己读。
- 每个问题要写：位置、类型、危害、证明方式（测试或运行结果）。
- 验证闭环：说明用哪些检查来保证改动可靠，以及这些检查能不能发现你找到的问题。
- 权限与安全清单：每一项授权都写明为什么需要、风险是什么。
- 只在练习项目的独立分支上操作，不对任何他人的系统使用 Agent。

## 操作步骤

1. 先自己读改动（`git diff`），不借助 Agent，列出疑点。
2. 逐个验证疑点：运行、写测试、查文档，判断是不是真的问题。
3. 把自己的疑点清单交给 Agent，让它指出可能遗漏的问题；逐条判断是否采纳。
4. 修复必须修的问题，或写明不修的理由；补充能发现这些问题的测试。
5. 写验证闭环说明和权限与安全清单。
6. 写使用复盘：哪些任务适合交给 Agent，哪些不适合，返工的原因，如何改进。

- 提交补充的测试、修复后的代码及运行记录。
- 展示每个问题的证明、验证闭环能否发现这些问题，以及权限清单的理由。
