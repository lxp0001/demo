# 阶段七教师用:练习设置与评分说明(不发给学生)

## 一、三个功能的准备
| 功能 | 用在 | 需要准备 |
|---|---|---|
| 菜品搜索与分页 | 任务 7.1(对照实验) | 功能规格;**隐藏验收测试**(约 12 个,覆盖参数、边界、搜索词的安全处理);一份评分脚本 |
| 订单统计 | 任务 7.1 | 功能规格;隐藏验收测试(统计正确、只统计本人数据、空数据);访问控制检查 |
| 订单取消与退款状态 | 任务 7.2(被审查) | 一个**由 Agent 生成并埋入问题的分支或补丁**;对应的正确版本;隐藏测试 |

## 二、7.2 建议埋入的问题(8 到 10 个,难度不一)
| 编号 | 问题 | 类型 |
|---|---|---|
| E1 | 调用了项目里不存在的函数或接口 | 臆造接口 |
| E2 | 顺手修改了与功能无关的文件 | 越界修改 |
| E3 | 削弱了已有测试(放宽断言或加了跳过) | 削弱验证 |
| E4 | 把密钥或令牌写进代码或日志 | 敏感信息 |
| E5 | 引入了未声明的依赖,或没有更新依赖清单 | 依赖问题 |
| E6 | 增加了需求之外的接口 | 范围蔓延 |
| E7 | 取消和退款的状态流转没有并发保护,可能重复退款 | 并发 |
| E8 | 取消订单没有检查订单归属 | 访问控制 |
| E9 | 退款金额用浮点数计算 | 金额精度 |
| E10 | 出错时把内部细节返回给前端 | 信息泄露 |

请在正确版本上先确认所有测试通过,再埋问题。

## 三、对照实验的评分提醒
- 学生可以使用不同的 Agent 工具,**只评价使用方式和过程,不比较工具**。
- 对照实验的数据只有一次,样本很小,评分看**数据是否真实、结论是否谨慎、是否写出局限**,不看哪种方式"赢"。
- 要求学生在文档里写明所用工具,以及项目约定文件、权限配置的具体做法,因为不同工具名称和写法不同。

## 四、评分建议
- **自动检查**:7.1 用隐藏验收测试、依赖规则、干净克隆启动检查;7.2 看学生补充的测试能否在埋问题的版本上失败、在正确版本上通过。
- **AI 评价**:拆解与规格是否在使用 Agent 之前完成;疑点清单是否在使用 Agent 之前完成;结论是否有数据支持。
- **人工评价**:现场解释一个审查发现和一项授权的理由。
- 学生找到的、不在上表中的合理问题,经确认后同样给分。

## 五、还需要确认和准备的内容
- 学生使用 Agent 所需的账号、额度和网络条件(对照实验要做两遍,需要足够额度);条件受限时,可以缩小功能 A 的规模。
- 权限配置:是否允许 Agent 自行执行命令,是否要求在隔离分支或沙箱中运行。
- 项目约定文件的写法示例(已提供工具无关的版本),各工具的具体文件名请你们核对后补充。
- 功能规格、隐藏测试和埋问题的分支。
