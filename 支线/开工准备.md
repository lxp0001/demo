# 开工准备｜第一次在本机运行页面

适用对象：编程零基础学生。建议在阶段 2 开始前完成，约 30—45 分钟。本练习只检查环境和基本操作，不要求理解语法。

## 1. 检查工具

确认电脑能打开 VS Code 和 Chrome。在 VS Code 中打开一个自建文件夹，再打开“终端”，依次运行：

```powershell
node --version
npm --version
py --version
git --version
```

每条命令能显示版本号即可。若 `py` 不可用，再试 `python --version`。某项报错时，保留完整报错截图，先不要反复安装多个版本。阶段 2 要用 Node.js、npm 和 Python；Git 从后续的版本管理练习开始使用。SQLite 由 Python 的 `sqlite3` 模块提供，本练习不要求单独安装数据库软件。

## 2. 跑通一次“修改—运行—查看”

在刚才的文件夹中新建 `hello.html`，输入：

```html
<!doctype html>
<html lang="zh-CN">
  <meta charset="utf-8">
  <title>第一次运行</title>
  <h1>你好，软件工程！</h1>
</html>
```

保存文件，在该文件夹的终端运行 `py -m http.server 8000`（若前一步使用的是 `python`，这里也改用 `python`）。在 Chrome 打开 `http://localhost:8000/hello.html`。把标题改成自己的名字，保存并刷新页面，确认变化。终端需要保持运行；完成后按 `Ctrl+C` 停止。

## 3. 试一次正确的 AI 求助

向可用的 AI 工具提问：“请用零基础学生能懂的话，解释我刚才的 `hello.html`、本地服务和浏览器各做了什么。只解释，不修改文件。”对照实际操作，指出它说对的一点和仍不理解的一点。不要上传账号密码、令牌或真实个人数据。

如果暂时无法使用 AI，可由教师提供一段示例问答，学生仍需独立核对和提问。

## 完成标志

提交一张页面截图和一小段记录：哪些版本检查通过、标题修改是否生效、遇到的一个问题及其报错或解决办法。**报错也是有效学习证据**，不要求所有学生在课前自行解决环境问题。

教师课前需确认：学生可使用的工具安装方式、网络与账号条件，以及阶段 2 的起始项目和统一启动命令；课堂上预留处理安装问题的时间。
