# 任务 2.1｜实现一个前端页面

## 任务目标

为食堂点餐设计并实现菜品列表页：先写草图和需求，再让 Agent 实现，按需求逐项验收，并读懂生成的代码。

## 技术与范围

- 前端：Vite + 原生 TypeScript，在 Chrome 中运行。
- 页面：菜品列表页，展示名称、价格、库存状态；点击「加入」后，页面顶部显示已选件数。
- 数据：先使用写在代码里的假数据。
- 要处理两种特殊情况：没有菜品、菜品已售罄。
- 不增加登录、真实下单和后端接口。

## 操作步骤

1. 自己画页面草图，标出区域、内容和可点击的位置。
2. 写需求说明：展示的信息、用户操作、数据字段、特殊情况和不做的内容，每条都要能用「是/否」验收。
3. 把草图和需求交给 Agent，限定范围，先看计划，再动手。
4. 运行 `npm run build` 和 `npm run dev`，在 Chrome 中按需求逐项验收，并用开发者工具指出页面各部分对应的元素。
5. 读懂生成的代码，写下类型定义、渲染函数和点击处理所在的位置。
