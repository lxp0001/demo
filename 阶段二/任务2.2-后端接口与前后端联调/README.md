# 任务 2.2｜后端接口与前后端联调

## 任务目标

为任务 2.1 的菜品列表增加后端查询接口，将页面中的假数据替换为接口返回的数据，并能依据浏览器与后端证据定位联调问题。

## 技术与范围

- 后端：Python + FastAPI。数据先写在代码里的列表中。
- 接口：`GET /api/dishes` 查询列表，`GET /api/dishes/{id}` 查询一项；不存在的 id 返回 404。
- 前端：调用列表接口，并处理加载中、失败和空列表。
- 不增加登录、写入接口或数据库；数据库在任务 2.3 引入。

## 操作步骤

1. 自己先写接口地址、方法、返回字段、成功和错误情况。
2. 检查前端 `Dish` 与后端 JSON 的字段是否一致，记录一处可能不一致的预测。
3. 让 Agent 按接口说明实现后端，先看计划，再验收 `/docs` 中的两个接口。
4. 将页面数据改为 `fetch` 请求，同时运行前后端。
5. 用浏览器 Console、Network 和后端日志定位问题，记录解决过程。
