# 任务 2.3｜使用 SQLite 数据库

## 任务目标

把接口的数据从代码里的列表迁移到 SQLite：设计一张菜品表，用脚本建库，并验证页面上的数据确实来自数据库。

## 技术与范围

- 数据库：SQLite，使用 Python 标准库 `sqlite3`，不使用 ORM。
- 表：一张菜品表；建库脚本可以重复运行，初始数据不少于 3 条。
- 接口：`GET /api/dishes`、`GET /api/dishes/{id}` 改为从数据库读取，查询使用参数化。
- 不增加多表关系、写入接口和复杂查询。
- `.db` 文件不提交，提交建库脚本。

## 操作步骤

1. 自己写表设计草案：表名、列名与类型、主键、是否可空、初始数据。
2. 整理前端 `Dish` 字段与数据库列的对应关系，布尔值用 0 和 1 表示。
3. 让 Agent 编写建库脚本并改造接口，先看计划，再动手。
4. 运行建库脚本、启动后端，用 `/docs` 调用接口，并用数据库查看工具核对内容。
5. 在数据库里修改一条记录，不改代码，刷新页面，确认页面跟着变化。
