# 任务3｜追踪一个核心功能：流程与数据

## 任务目标

从一个软件系统中选一个范围清晰的核心功能，追踪用户一次操作从开始到结果的过程，并观察或推测过程中涉及的数据变化。本任务从任务2的整体系统地图缩小到一条具体功能路径。

## 功能选择建议

选择可在几分钟内描述清楚的功能，例如搜索一条内容、提交表单、收藏项目、创建订单/预约（使用演示数据）。避免选择“整个 AI 如何工作”等范围过大的题目。不要提交真实个人信息或真实支付。

## 操作步骤

简单起见，使用提供的demo应用。

1. 先独立预测功能步骤和可能涉及的数据，并写下判断依据。
2. 实际操作或观看案例演示，按顺序记录每一步。
3. 标出每一步产生、读取或改变了什么数据；无法观察的内部处理要标“推测”。
4. 对照预测与实际，记录至少一个异常/分支，例如输入无效、无结果、网络失败或重复提交。
5. 让 AI 检查流程是否有跳步或提出其他解释，再依据体验或材料核验，说明采纳与否的理由。

## AI 提问参考

> 请根据我的操作记录【粘贴记录】整理一张“用户操作—页面反馈—系统处理—数据变化”的流程表。不要把未观察到的后端细节写成事实；请指出可能缺失的步骤和需要我确认的问题。
