# 第二阶段｜前后端基础：食堂点餐系统

本阶段围绕同一个“食堂点餐”教学项目，依次完成页面、接口与数据库读取。学生先写草图或设计草案，再让 Coding Agent 实现，最后亲自运行、核对和解释结果。

| 任务 | 学习重点 | 本任务完成时能看到什么 |
|---|---|---|
| 2.1 实现一个前端页面 | 页面需求、数据类型、运行验收 | 使用假数据的菜品列表页 |
| 2.2 后端接口与前后端联调 | 接口约定、调用验收、问题定位 | 页面从 FastAPI 查询菜品 |
| 2.3 使用 SQLite 数据库 | 单表设计、建库脚本、来源验证 | 页面数据来自 SQLite |

## 学生完成方式

每项任务保留“独立草案 → Agent 任务说明与回应 → 运行证据 → 人工判断与修订”。不要求背诵全部语法，但要能说明自己交给 Agent 的要求、运行结果和关键数据流。

三个任务可以在同一个代码项目上依次完成。每项任务的填写模板可作为该任务的学习记录；代码、草图、截图和测试证据按任务 README 中的清单一同提交。

## 范围说明

阶段二只实现菜品浏览与页面上的“已选件数”。不做登录、真实下单、写入数据库、多表关系或支付。
