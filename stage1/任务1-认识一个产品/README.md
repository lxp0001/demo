# 任务1｜认识一个产品：用户与功能

## 任务目标

选择一个你能体验或能通过教师材料了解的软件产品，弄清楚它服务谁、解决什么问题、提供哪些核心功能。可以选择 AI 产品，也可以选择日常软件；建议选一个功能和场景比较熟悉的产品。

## 操作步骤

1. 先写下体验前的猜测和想验证的问题，不查 AI。
2. 写明产品名称、类别和信息来源。
3. 描述主要用户及其需求，选出2—3个核心功能，不必罗列全部功能。
4. 亲自完成一次小体验，记录输入、操作和结果；若无法体验，使用教师材料并注明。
5. 把观察交给 AI，请它整理总结；对照实际证据核对，并保留你接受、修改或拒绝建议的理由。

## AI 提问参考

> 我正在了解【产品名】。以下是我亲自观察到的信息：【粘贴观察】。请仅根据这些材料，总结它的目标用户、解决的问题和2—3项核心功能。把事实与推测分开，并指出哪些信息还需要核实。不要补充未经材料支持的功能。

## 提交

完成《01-产品观察与总结.md》。最终内容包括产品与来源、用户与需求、核心功能、体验记录、AI 总结与核对、个人判断。
