# 任务 1.2｜拆解一个软件系统

## 任务目标

从任务 1.1 的功能清单出发，把产品拆成前端、后端、数据和外部服务，画出模块关系图，并审查 AI 给出的参考拆解。

## 技术与范围

- 不需要写代码。
- 起点：任务 1.1 的产品和核心功能清单。
- 产出：功能与模块对应表、模块关系图。
- 真实产品的后端看不到，要标注哪些是“看到的”、哪些是“推测的”，并写出依据。
- 图不要求漂亮，要求别人能看懂。

## 操作步骤

1. 从任务 1.1 的功能清单出发，每个功能一行。
2. 对每个功能，写出用到的前端页面、后端处理、数据和外部服务，并标注依据。
3. 画模块关系图：用箭头表示谁调用谁，并在箭头上标出传递的数据。
4. 让 AI 给一版参考拆解，审查哪里错、哪里漏，并说明理由。
5. 对照功能清单检查：每个功能的每一环是否都有依据。

## AI 提问参考

> 下面是我拆解〔产品名称〕的功能与模块对应表。请只指出可能错误或遗漏的地方，并说明你判断的依据；对你不能确定的内容，请明确说明是推测。

- 提交模块关系图。
- 展示功能与模块对应表、AI 的审查意见，以及你的取舍。
