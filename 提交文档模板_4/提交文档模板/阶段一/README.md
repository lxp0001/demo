# 第一阶段｜软件系统认知：从使用到看懂

本阶段不写代码。学生选定一个真实的软件产品，依次完成产品认识、系统拆解和功能追踪，从用户视角、构造视角和运行视角看懂同一个软件。学生先独立思考，再请 Coding Agent 补充，最后自己判断取舍。

| 任务 | 学习重点 | 本任务完成时能看到什么 |
|---|---|---|
| 1.1 认识一个产品 | 用户视角（需求分析）：谁在用、解决什么问题 | 使用记录和产品说明 |
| 1.2 拆解一个软件系统 | 构造视角（结构视图）：每个功能靠哪些模块完成 | 功能与模块对应表、模块关系图 |
| 1.3 追踪一个核心功能 | 运行视角（运行时视图）：一次操作如何经过各个模块 | 功能流程图和说明 |

## 学生完成方式

每项任务保留“独立思考 → Agent 补充与回应 → 证据 → 人工判断与修订”。三个任务围绕同一个产品：任务 1.2 从任务 1.1 的功能清单出发，任务 1.3 从中选一个核心功能。

## 范围说明

- 不写代码。
- 真实产品的后端看不到，内部结构只能推断，要在图和说明里标注“看到的”和“推测的”。
- 追踪只限于自己浏览器里自己的操作，不抓取他人数据，不绕过产品的限制；截图和提交内容中去掉账号、手机号、令牌等个人信息。
- 优先选有网页版的产品。只有客户端的产品，用观察法完成追踪。
- 可选：在老师提供的教学示例应用（食堂点餐）上验证追踪方法。
