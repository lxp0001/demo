# 任务 1.3｜追踪一个核心功能

## 任务目标

从任务 1.1 中选一个核心功能，追踪一次操作从点击到返回的完整过程，标出经过的模块和数据，并区分观察到的和推测的。

## 技术与范围

- 不需要写代码。
- 功能：任务 1.1 清单中的一个核心功能（如登录、搜索、下单、预约）。
- 网页版：用 Chrome 开发者工具的 Network 面板观察请求。
- 客户端：用观察法，包括录屏、逐步截图、公开文档，并写出推测的依据。
- 只观察自己浏览器里自己的操作，不抓取他人数据，不绕过产品的限制。
- 截图和提交内容中去掉账号、手机号、令牌等个人信息。
- 可选：在老师提供的教学示例应用（食堂点餐）上验证追踪方法。

## 操作步骤

1. 选定功能，先写出预计经过的步骤（预测）。
2. 实际操作，用 Network 面板或观察法收集证据。
3. 画流程图：点击、前端、请求、后端、数据、返回，并标注哪些是观察到的、哪些是推测的。
4. 让 AI 解释并检查流程，自己核对，不把推测当成事实。
5. 对比预测和证据，记录不一致的地方和你的修订。

## 提交

- 提交流程图和已遮盖个人信息的截图。
- 展示预测、证据、观察与推测的区分，以及预测与证据的差异。
