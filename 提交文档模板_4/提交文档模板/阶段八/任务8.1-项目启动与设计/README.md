# 任务 8.1｜项目启动与设计

## 任务目标

与真实需求方澄清需求并确认范围，完成设计包、质量计划和风险与合规清单，拆解任务、确定里程碑，并通过设计评审。

## 技术与范围

- 项目：经老师审批的真实项目（校内需求方、企业导师项目或开源项目）。
- 需求：至少一次需求访谈；整理成用户故事、验收标准、不做的内容和假设清单，并让需求方确认。
- 设计：接口、数据、模块与职责、架构决策记录（沿用第三、六阶段的方法）。
- 质量计划：测试计划和威胁清单初稿（沿用第四、五阶段的方法）。
- 风险与合规：数据与隐私、保密与 Agent 使用边界、开源许可证。
- 管理：任务拆解、里程碑、项目约定文件、协作约定（沿用第七阶段的方法）。
- 本任务不编写业务代码。

## 操作步骤

1. 访谈需求方，记录对方的原话和未决问题（可参考 `02-需求访谈记录模板.md`）。
2. 整理需求：用户故事、验收标准、不做的内容和假设；把整理结果发回需求方确认，保留确认记录。
3. 做设计包：接口、数据、模块与职责、架构决策记录。
4. 写测试计划、威胁清单初稿，以及风险与合规清单。
5. 拆解任务，定里程碑，写项目约定文件和协作约定。
6. 做设计评审：汇报设计，记录评审意见、取舍和修改。

## 提交

- 完成《01-项目启动与设计记录.md》，需求确认记录和设计要在使用 Agent 实现之前完成。
- 提交访谈记录、需求确认记录和设计文档。
- 展示假设的确认情况、风险与合规清单，以及设计评审的意见和取舍。
