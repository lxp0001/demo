# 提交文档模板

命名规则:`阶段X/任务X.X-任务名/`。每个阶段目录下有 `README.md`(阶段说明)和 `填写示例.md`;每个任务目录包含:

- `README.md`:任务要求(目标、技术与范围、操作步骤、AI 提问参考、提交)
- `01-文档名.md`:学生填写的提交文档,合并了设计、验收记录和代码走读

阶段四至阶段八的目录下另有 `教师用/`,内含缺陷或问题的设置与评分说明,**不发给学生**。

使用方法:复制到自己的仓库,按提示填写提交文档,填完删除提示和示例行。截图放在任务目录下的 `images/`;代码放在 `frontend/`、`backend/`、`scripts/`、`tests/`。不提交 `node_modules/`、`.venv/`、`*.db`。
