# AI Engineering Builder｜课程示例与任务资料

本课程以项目和任务为主线，训练学生从观察问题、设计方案到实现、验证和交付软件的完整过程。学生可以使用 AI 和 Coding Agent 辅助学习与开发，但需要先独立思考，保留证据，并对 AI 的建议和产出作出判断。

## 课程主线

**阶段 2—7 统一使用同一个“食堂点餐系统”。** 每个阶段在前一阶段的成果上增加能力或改进质量，不更换业务系统。阶段 3 的订单与支付、阶段 4 的测试、阶段 5 的安全与性能、阶段 6 的架构改造、阶段 7 的 Coding Agent 实践，均以该系统为载体。教师可能为练习提供正确版、缺陷版或结构混乱版；这些是同一系统的不同教学版本，不是新项目。

阶段 1 用熟悉的产品和演示系统建立软件系统认知，不要求使用食堂项目。阶段 8 转入新的综合项目，运用前面形成的设计、开发、测试、安全、架构和 AI 协作方法。

| 阶段 | 主题 | 与课程主线的关系 |
|---|---|---|
| [阶段 1](阶段1/README.md) | 认识产品与理解系统 | 认知准备，使用产品观察和演示案例 |
| [阶段 2](阶段2/README.md) | 前后端基础 | 建立食堂点餐系统：页面、接口、数据库 |
| [阶段 3](阶段3/README.md) | 接口与系统设计 | 在同一系统中加入下单、订单数据和模拟支付 |
| [阶段 4](阶段4/README.md) | 测试与调试 | 对同一系统设计测试并定位缺陷 |
| [阶段 5](阶段5/README.md) | 安全与性能 | 对同一系统进行安全检查、测量与优化 |
| [阶段 6](阶段6/README.md) | 软件架构 | 对同一系统分析架构并安全重构 |
| [阶段 7](阶段7/README.md) | Coding Agent 的系统使用 | 在同一系统中练习规格、审查和验证 |
| [阶段 8](阶段8/README.md) | 综合项目 | 启动新的项目，综合运用前七阶段的方法 |

零基础学生可在阶段 2 前先完成[开工准备](支线/开工准备.md)，检查工具并在本机运行第一个页面。

各阶段的具体任务、提交内容和范围以对应目录中的 README 为准。`pptx/` 存放配套课件；`教师用/` 材料仅供教师备课和评分，不应直接发给学生。
